# ber-cli Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `ber-cli`, a Bend-native CLI that mirrors the public API of `ber-core` 1:1 with human + `--json` output and guiding errors.

**Architecture:** Thin shell over `ber-core`: pure modules (`Args`, `Input`, `Render`) carry laws + `{==}` proofs; one thin module (`Run`) plus `cli.bend` owns all `IO`/`Store` effects and is covered only by `*_check.bend` wiring checks. `ber-core` is consumed as a published package; MyLSM is never named directly.

**Tech Stack:** Bend 2.0.x, `ber-core-store@0.1.2.0`, `bend-kit-json` + `bend-codec-lib` (via ber-core pins), `bolt` linter.

**Workflow (overrides TDD — proof-driven per `AGENT.md`):** claim in `LAWS.bend` → code + proof in `PROOF.bend` (`{==}` per law) → `tests/*_check.bend` ONLY for IO/Sess wiring. Gate every commit: `bend PROOF.bend` green + `bolt` 0 errors.

**Spec:** `docs/superpowers/specs/2026-09-27-ber-cli-design.md`.

---

## File map

| File | Responsibility |
|---|---|
| `pack.json` | Package manifest + ber-core dependency pin |
| `bolt.bend` | Linter config (copy of ber-core: correctness=error, rest=warn) |
| `LAWS.bend` | All CLI laws (grows per task; final = 6 families, §8 of spec) |
| `PROOF.bend` | One `def Laws.<name>` per law, `{==}`-closed |
| `cli.bend` | `main`: `IO.args` → `Run.run_argv` |
| `src/Args.bend` | PURE: `ValueSource`, `Command`, `GlobalOpts`, `parse_command`, `parse_opts`, `usage_text` |
| `src/Input.bend` | PURE: `source_to_value` (flags → `Value.Value`; `FromFile` → `None`, files are read in `Run`) |
| `src/Render.bend` | PURE: `Outcome`, `render_human`, `render_json`, `exit_code_of`, `hint_for` |
| `src/Run.bend` | EFFECTS ONLY: `execute(store_dir, cmd) -> IO(Outcome)`, `run_argv(argv) -> IO(Unit)`; delegates 1:1 to `Ber.*` |
| `tests/` | NO EXISTE por decisión explícita: cero tests. El shell de efectos se valida con smoke manual del binario (Task 7) |

### Task 2: Args — pure CLI parsing

**Files:**
- Create: `src/Args.bend`
- Modify: `LAWS.bend` (append Args family), `PROOF.bend` (append proofs)

Design note (Bend constraints discovered during implementation): `match` cannot
scrutinize computed values, locals, or mutually-recursive defs, and the
`List<String>` from `IO.args` is single-use. Therefore argv is consumed in ONE
structural pass into `ArgvSplit{head_word, sub_word, flag_map}` — every token
links to its successor in a `Map` (lookups via Base `Map.get`/`Map.has`, never
comparing), head/sub slots tracked by `Nat` counter patterns (`0n`/`1n+p`).
Every `String.eq` travels as a `Bool` argument into a decide-helper matching
on the parameter. Defs are leaf-first. `--session` parses per command;
`session_or` prefers it over the global flag (with laws).

```python
import Base

# One CLI value source; FromFile resolves in Run (needs File IO), never here.
type ValueSource is Data:
  FromText{content: String}
  FromJson{json_text: String}
  FromBlobHex{hex_text: String}
  FromFile{file_path: String, kind_name: String}

# Every subcommand (spec table §4) plus Help and UsageError.
type Command is Data:
  RecordPut{session_id: String, namespace_name: String, record_id: String, source: ValueSource}
  RecordRm{session_id: String, namespace_name: String, record_id: String}
  RecordGet{namespace_name: String, record_id: String, commit_id: String}
  CommitCreate{session_id: String, parents: List<&2, String>, metas: List<&2, String>}
  CommitShowTree{commit_id: String}
  Diff{first_id: String, second_id: String, verbose: Bool}
  Merge{first_id: String, second_id: String, strategy_name: String}
  CertVerify{first_id: String, second_id: String, base_id: String, tree_hash: String, strategy_name: String, laws: List<&2, String>}
  Write{session_id: String, namespace_name: String, record_id: String, source: ValueSource, parents: List<&2, String>}
  Compare{first_id: String, second_id: String}
  MergeVerify{first_id: String, second_id: String}
  Help{topic: String}
  UsageError{message: String}

# Global flags (spec §4 header).
type GlobalOpts is Data:
  Opts{store_dir: String, session_id: String, json_out: Bool, colors_on: Bool, verbose: Bool}

def default_opts() -> GlobalOpts:
  Opts{"./.ber", "", False{}, False{}, False{}}

def store_dir_of(opts: GlobalOpts) -> String:
  match opts:
    case Opts{store_dir, session_id, json_out, colors_on, verbose}:
      store_dir

# Reads --flag value pairs; missing value yields "".
def flag_value(+flag_name: String, args: List<String>) -> String:
  match args:
    case Nil{}:
      ""
    case Con{head_arg, tail_args}:
      match String.eq(head_arg, flag_name):
        case True{}:
          match tail_args:
            case Nil{}:
              ""
            case Con{+value_arg, rest_args}:
              value_arg
        case False{}:
          flag_value(flag_name, tail_args)

def has_flag(+flag_name: String, args: List<String>) -> Bool:
  match args:
    case Nil{}:
      False{}
    case Con{head_arg, tail_args}:
      match String.eq(head_arg, flag_name):
        case True{}:
          True{}
        case False{}:
          has_flag(flag_name, tail_args)

# Exactly one of --text/--json/--blob-hex/--file; zero or two+ is a UsageError.
def parse_source(args: List<String>) -> ValueSource:
  +text_val : String = flag_value("--text", args)
  +json_val : String = flag_value("--json", args)
  +hex_val : String = flag_value("--blob-hex", args)
  +file_val : String = flag_value("--file", args)
  match String.eq(text_val, ""):
    case False{}:
      FromText{text_val}
    case True{}:
      match String.eq(json_val, ""):
        case False{}:
          FromJson{json_val}
        case True{}:
          match String.eq(hex_val, ""):
            case False{}:
              FromBlobHex{hex_val}
            case True{}:
              match String.eq(file_val, ""):
                case False{}:
                  FromFile{file_val, flag_value("--kind", args)}
                case True{}:
                  FromText{""}

def decide_source_missing(is_empty: Bool, +namespace_name: String, +record_id: String) -> Command:
  match is_empty:
    case True{}:
      UsageError{"record-put-needs-value"}
    case False{}:
      RecordPut{"", namespace_name, record_id, FromText{""}}

def parse_record_put(args: List<String>) -> Command:
  +namespace_name : String = flag_value("--ns", args)
  +record_id : String = flag_value("--record", args)
  +source : ValueSource = parse_source(args)
  match source:
    case FromText{content}:
      match String.eq(content, ""):
        case True{}:
          decide_source_missing(String.eq(flag_value("--file", args), ""), namespace_name, record_id)
        case False{}:
          RecordPut{"", namespace_name, record_id, source}
    case FromJson{json_text}:
      RecordPut{"", namespace_name, record_id, source}
    case FromBlobHex{hex_text}:
      RecordPut{"", namespace_name, record_id, source}
    case FromFile{file_path, kind_name}:
      RecordPut{"", namespace_name, record_id, source}

def parse_record(args: List<String>) -> Command:
  match args:
    case Nil{}:
      UsageError{"record-needs-subcommand"}
    case Con{+sub_name, rest_args}:
      match String.eq(sub_name, "put"):
        case True{}:
          parse_record_put(rest_args)
        case False{}:
          match String.eq(sub_name, "rm"):
            case True{}:
              RecordRm{"", flag_value("--ns", rest_args), flag_value("--record", rest_args)}
            case False{}:
              match String.eq(sub_name, "get"):
                case True{}:
                  RecordGet{flag_value("--ns", rest_args), flag_value("--record", rest_args), flag_value("--at", rest_args)}
                case False{}:
                  UsageError{"unknown-record-subcommand"}

def parse_command(argv: List<String>) -> Command:
  match argv:
    case Nil{}:
      UsageError{"empty-argv"}
    case Con{+head_word, rest_words}:
      match String.eq(head_word, "record"):
        case True{}:
          parse_record(rest_words)
        case False{}:
          match String.eq(head_word, "diff"):
            case True{}:
              Diff{flag_value("--from", rest_words), flag_value("--to", rest_words), has_flag("--verbose", rest_words)}
            case False{}:
              match String.eq(head_word, "help"):
                case True{}:
                  Help{flag_value("--for", rest_words)}
                case False{}:
                  UsageError{"unknown-command"}

def parse_opts(argv: List<String>) -> GlobalOpts:
  +store_val : String = flag_value("--store", argv)
  match String.eq(store_val, ""):
    case True{}:
      Opts{"./.ber", flag_value("--session", argv), has_flag("--json", argv), has_flag("--colors", argv), has_flag("--verbose", argv)}
    case False{}:
      Opts{store_val, flag_value("--session", argv), has_flag("--json", argv), has_flag("--colors", argv), has_flag("--verbose", argv)}

def usage_text(+topic: String) -> String:
  "ber record put --ns N --record R (--text T | --json J | --blob-hex H | --file F --kind K)\nber record get --ns N --record R --at COMMIT\nber diff --from A --to B [--verbose]\nber merge --first A --second B\nber --help"
```

```python
import Base

# Every CLI result maps to exactly one Outcome; Run owns the Ber.* → Outcome
# mapping, this module owns Outcome → text/code/hint (all pure).
type Outcome is Data:
  Ok{text: String}
  Merged{commit_id: String}
  Conflict{count_text: String, keys_text: String, first_id: String, second_id: String}
  Unprovable{reason: String}
  Absent{what: String}
  UsageError{message: String}
  IoError{message: String}

type HumanOpts is Data:
  Human{color_on: Bool, verbose: Bool}

def plain_opts() -> HumanOpts:
  Human{False{}, False{}}

def opts_of(colors_on: Bool, verbose: Bool) -> HumanOpts:
  Human{colors_on, verbose}

def exit_code_of(outcome: Outcome) -> U32:
  match outcome:
    case Ok{text}:
      (0 : U32)
    case Merged{commit_id}:
      (0 : U32)
    case Conflict{count_text, keys_text, first_id, second_id}:
      (10 : U32)
    case Unprovable{reason}:
      (20 : U32)
    case Absent{what}:
      (30 : U32)
    case UsageError{message}:
      (2 : U32)
    case IoError{message}:
      (3 : U32)

def hint_for(outcome: Outcome) -> String:
  match outcome:
    case Conflict{count_text, keys_text, first_id, second_id}:
      "hint: ber diff --from " ++ first_id ++ " --to " ++ second_id ++ " --verbose"
    case Unprovable{reason}:
      match String.eq(reason, "no-common-ancestor"):
        case True{}:
          "hint: ber commit show-tree --at <each-parent> to review parents"
        case False{}:
          match String.eq(reason, "verify-failed"):
            case True{}:
              "hint: ber certificate verify --first <a> --second <b> --base <c> --tree <h>"
            case False{}:
              "hint: check parents and strategy (only union-disjoint)"
    case Absent{what}:
      "hint: check --ns/--record/--at; absent reads exit 30"
    case UsageError{message}:
      "hint: ber --help"
    case Ok{text}:
      ""
    case Merged{commit_id}:
      ""
    case IoError{message}:
      "hint: check --store dir and file permissions"

def render_human(outcome: Outcome, +opts: HumanOpts) -> String:
  match outcome:
    case Ok{text}:
      text
    case Merged{commit_id}:
      "merged:" ++ commit_id
    case Conflict{count_text, keys_text, first_id, second_id}:
      "conflict:" ++ count_text ++ " " ++ keys_text ++ "\n" ++ hint_for(outcome)
    case Unprovable{reason}:
      "unprovable:" ++ reason ++ "\n" ++ hint_for(outcome)
    case Absent{what}:
      "absent:" ++ what ++ "\n" ++ hint_for(outcome)
    case UsageError{message}:
      "usage-error:" ++ message ++ "\n" ++ hint_for(outcome)
    case IoError{message}:
      "io-error:" ++ message ++ "\n" ++ hint_for(outcome)

def render_json(outcome: Outcome) -> String:
  match outcome:
    case Ok{text}:
      "{\"status\":\"ok\",\"output\":\"" ++ text ++ "\"}"
    case Merged{commit_id}:
      "{\"status\":\"merged\",\"commit\":\"" ++ commit_id ++ "\"}"
    case Conflict{count_text, keys_text, first_id, second_id}:
      "{\"status\":\"conflict\",\"count\":\"" ++ count_text ++ "\",\"keys\":\"" ++ keys_text ++ "\"}"
    case Unprovable{reason}:
      "{\"status\":\"unprovable\",\"reason\":\"" ++ reason ++ "\"}"
    case Absent{what}:
      "{\"status\":\"absent\",\"what\":\"" ++ what ++ "\"}"
    case UsageError{message}:
      "{\"status\":\"usage-error\",\"message\":\"" ++ message ++ "\"}"
    case IoError{message}:
      "{\"status\":\"io-error\",\"message\":\"" ++ message ++ "\"}"

def render_outcome(outcome: Outcome, json_out: Bool, +opts: HumanOpts) -> String:
  match json_out:
    case True{}:
      render_json(outcome)
    case False{}:
      render_human(outcome, opts)
```
